# Task memory

Task files are the durable working memory for one change request. Create
`<YYYY-MM-DD-HHMM>-<slug>.md` before editing, and keep one active task per request.

Use this shape:

```markdown
# Title
Status: active

## Goal
## Hypothesis (files/symbols)
## Questions and answers
## Plan
## Blast radius
## Build filter
## Tests to run
## Findings (cache narrow reads here)
## Diff summary
## Verification
## Risks / deferred
```

Change `Status` to `complete` only after verification and fill every closeout section.
